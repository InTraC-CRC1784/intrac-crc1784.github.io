## Beginner

&nbsp;

- **R / Python** — Introduction to programming for data analysis
- **Linux / HPC Basics** — Working with the command line and cluster environments
- **Git** — Version control for reproducible research

---

## Intermediate

&nbsp;

- **Differential Expression Analysis** — Statistical methods for bulk RNA-seq
- **Seurat / Scanpy** — Single-cell RNA-seq analysis frameworks
- **Pathway & Gene Set Enrichment** — Functional interpretation of omics results

---

## Advanced

&nbsp;

- **Multi-omics Integration** — Methods for cross-modality data analysis
- **Nextflow Development** — Building and customising analysis pipelines
- **Machine Learning for Omics** — Applying ML approaches to biological data
- **Reproducible Research** — Best practices for open and reproducible science
